## Go live on GitHub Pages (about 5 minutes, no coding)

1. Log in to GitHub → **+ → New repository**.
   - Name it **`YOUR-USERNAME.github.io`** → the site opens at `https://YOUR-USERNAME.github.io`
   - or any name, e.g. **`scrollarc`** → the site opens at `https://YOUR-USERNAME.github.io/scrollarc/`
   - Keep it **Public** → **Create repository**.
2. On the new repo page click **uploading an existing file**.
3. Unzip this folder on your computer and drag **everything inside it** (`index.html`, `about.html`, the `assets`, `services` and `solutions` folders, etc.) into the upload box → **Commit changes**.
4. Go to **Settings → Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**.
5. Wait 1–2 minutes and refresh — the live link appears at the top of the Pages settings.

## After it is live

- Send the live URL to Claude so the canonical links, sitemap and social-share image links can be pointed at it (they currently use `https://YOUR-GITHUB-USERNAME.github.io` as a placeholder).
- Add the site to **Google Search Console** and submit `sitemap.xml`.
- Put the link in your Instagram bio, WhatsApp Business profile and Google Business Profile.
- Custom domain later (e.g. scrollarc.in): **Settings → Pages → Custom domain**, then add the DNS records GitHub shows.
